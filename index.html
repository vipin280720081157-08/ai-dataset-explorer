About & Architecture

        |                                 |
        +----------------+----------------+

            Consistent Pre-ML Insights

Both implementations share identical parsing rules, type inference logic, and statistical definitions. The Base R pipeline runs locally via R/RStudio with zero external dependencies, while the web application runs entirely client-side in the browser.

Inspection Rules & Standards

Rule / Metric Standard Applied
Missing ValuesEmpty strings, NA, N/A, NaN, NULL, null (case-insensitive, whitespace-trimmed).
Numerical TypeEvery non-missing value parses as a valid numeric literal (integers, floats, scientific notation).
Date TypeValues conforming to ISO-8601 calendar format (YYYY-MM-DD).
Categorical TypeText columns and discrete non-numeric categories.
Duplicate RowsExact match across every column with a previously observed row.
High CardinalityCategorical attributes containing greater than 10 unique values.
Mixed TypeText columns where 80% or more non-missing values resemble numbers.
Frequency Top-NTop 5 most frequent categories; ties sorted alphabetically.
PrecisionCalculations and percentage metrics rounded to 2 decimal places.

Principles

  • Non-Destructive: Strictly read-only analysis; no rows or columns are altered or dropped automatically.
  • Objective: Reports empirical counts and observations without subjective or arbitrary scoring.
  • Privacy-First: All uploaded files in the web interface are processed locally inside the browser.
